Replace the ``STORE_FAST_LOAD_FAST`` instruction with :opcode:`STORE_FAST_LOAD_FAST_BORROW`, which pushes a borrowed reference like a standalone :opcode:`LOAD_FAST_BORROW`. A ``STORE_FAST``; ``LOAD_FAST_BORROW`` pair is fused again, while a pair whose load must keep a strong reference is no longer fused. Patch by Pieter Eendebak.
