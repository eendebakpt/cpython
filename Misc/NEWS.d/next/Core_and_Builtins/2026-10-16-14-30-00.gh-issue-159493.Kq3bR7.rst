Replace the ``STORE_FAST_LOAD_FAST`` instruction with :opcode:`STORE_FAST_LOAD_FAST_BORROW`, which pushes a borrowed reference like a standalone :opcode:`LOAD_FAST_BORROW`; a store/load pair whose load must keep a strong reference is no longer fused. This avoids reference count contention on the free-threaded build for code such as ``for x in it: f(x)`` written on a single line. Patch by Pieter Eendebak.
